## frontend
- `frontend/index.html` - Hosts the Vite root element for the React application.
- `frontend/package.json` - Declares React renderer scripts, Electron desktop launch commands, and frontend runtime or build dependencies; desktop dev now rebuilds `dist/` in watch mode and launches Electron without opening a renderer web port.
- `frontend/README.md` - Describes the Electron-first frontend workflow, the desktop-protocol renderer runtime with no client web port, local desktop persistence, and Flask subtitle-service environment variables.
- `frontend/eslint.config.js` - Configures frontend lint rules.
- `frontend/vite.config.js` - Configures the Vite frontend build and dev server.
- `frontend/electron/debugLog.mjs` - Writes structured JSONL desktop debug logs under the Electron user data directory, rotates the current log file when it grows too large, and exposes IPC handlers for writing or locating export-debug traces.
- `frontend/electron/main.mjs` - Starts the Electron desktop shell, serves the built renderer through `desktop://app` when no external dev URL is injected, manages the local Flask runtime, writes desktop or backend lifecycle events to the structured debug log file, registers native export IPC, and defines the desktop `isDeveloper` toggle used to reveal UI locator markers.
- `frontend/electron/preload.mjs` - Exposes desktop runtime configuration, the `isDeveloper` UI-marker flag, debug-log IPC methods, native export IPC methods, and local project storage IPC methods, including project-scoped voiceover save and restore calls, to the React renderer through a safe preload bridge.
- `frontend/electron/projectMediaProtocol.mjs` - Serves both renderer assets and stored project videos over the `desktop://app` Electron protocol, including byte-range video responses plus cross-origin resource headers so restored desktop videos can load inside the frame-preview canvas runtime without a local renderer HTTP server.
- `frontend/electron/projectStore.mjs` - Persists project metadata, creation timestamps, output-frame settings, subtitle layout and appearance settings, source videos, and saved voiceover audio under the workspace-local `projects/` folder during desktop development, falls back to legacy Electron `userData` roots when reading older projects or voiceover files, records voiceover filename, mime type, size, and duration inside project metadata, emits `desktop://app/project-media/...` URLs for dashboard previews and editor playback, and retries local project deletion when Windows still holds a transient file lock.
- `frontend/electron/projectStoreShared.mjs` - Centralizes Electron project-store root selection, filename builders, payload normalization, directory creation, and project metadata read or write helpers, including the dev-time repo-local `projects/` root plus legacy or configured fallback roots so the main project store can stay below the 400-line guardrail.
- `frontend/electron/export/exportCoordinator.mjs` - Coordinates the native fast export job in Electron main: resolves the source video plus optional saved voiceover input, writes selected image frame backgrounds plus subtitle overlay assets into the job directory, merges kept scenes, delegates chunked frame rendering to the framing pipeline, remuxes the final audio mix using the configured video and narration volumes when needed, and streams progress plus logs back to the renderer while tolerating renderer detaches during long exports.
- `frontend/electron/export/exportAudioStage.mjs` - Runs the native FFmpeg audio-stage helper that renders video-only, voiceover-only, or mixed export audio tracks before the final native remux so `exportCoordinator.mjs` stays under the 400-line guardrail.
- `frontend/electron/export/framePipeline.mjs` - Splits the native frame-render stage into adaptive duration-based timeline chunks, composes preset colors, cover-image backgrounds, or blurred video-derived fade backgrounds, now honoring the selected fade-strength preset when that mode is active, applies only the subtitle overlays active in each chunk, runs several FFmpeg framing workers in parallel, aggregates chunk progress back to the renderer, and concatenates the finished framed chunks into the final MP4.
- `frontend/electron/export/nativeFfmpeg.mjs` - Resolves the bundled `ffmpeg-static` binary, probes available hardware encoders, derives aggressive adaptive scene and frame worker plans from host CPU capacity plus timeline size, and runs native FFmpeg child processes while capturing stderr and progress output.
- `frontend/electron/export/scenePipeline.mjs` - Splits kept-scene extraction and concat into a parallel native FFmpeg pipeline with adaptive bounded worker concurrency for CPU-heavy export stages.
- `frontend/electron/subtitleFont.mjs` - Resolves a usable desktop font file from the host OS and exposes it over IPC so the FFmpeg subtitle burn-in path can render text inside the Electron runtime.
- `frontend/src/main.jsx` - Boots the React app into the DOM.
- `frontend/src/App.jsx` - Composes the dashboard and editor UI around the `useVideoEditor` hook, keeps both the timeline and export panels visible whenever a video is loaded instead of waiting for scene detection to finish, passes subtitle translation plus Vbee voiceover actions into the subtitle panel, threads the attached voiceover track plus shared subtitle layout settings into both the preview player and timeline, owns the shared left-nav section state so timeline voiceover or subtitle clicks can open the matching player config directly, and preserves the active editor session when the user returns to the dashboard during an in-flight background job so subtitle progress is still available on return.

- `frontend/src/hooks/useFrameExport.js` - Owns the editable output-frame settings, shared subtitle layout and appearance settings, the shared source-video and voiceover audio-mix state used by both preview and export, export lifecycle state, export diagnostics state, and the frame-aware export entrypoint shared by the player preview and export panel, still falling back to a synthetic full-video scene when no scene cuts exist yet.

## notebooks

## server
- `server/app.py` - Flask API entrypoint for the desktop subtitle service, with backend health check and proxy route composition only.
- `server/proxy_routes.py` - Registers transcription, translation, and Vbee voiceover proxy endpoints, preserves downstream status codes and error payloads for the desktop client, falls back to a local translation job when the upstream worker-based service is unavailable, and proxies Vbee audio downloads back through Flask so the Electron renderer can auto-download the result without cross-origin issues.
- `server/translation_fallback.py` - Runs local subtitle translation jobs via `deep-translator`, persists lightweight job metadata under `server/uploads/translation-jobs`, and serves the fallback `start -> status -> download` flow used when the upstream translation service cannot accept work.
- `server/requirements.txt` - Lists Flask and HTTP client dependencies for the subtitle-service backend.

## root
- `EXPORT_ARCHITECTURE.md` - Describes the target fast-export architecture: Electron-main native FFmpeg coordination, shared render manifests and overlay assets for parity, hardware probing, and chunk-level parallelism.
- `TASK.md` - Tracks active work, validation state, and follow-up refactors for this repository.
- `MAP.md` - Maps files to responsibilities so future tasks can route to the correct owner quickly.
