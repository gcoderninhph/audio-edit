# Desktop App Map

## .github
- `.github/agents/coder.agent.md` - Defines the workspace coding agent workflow, including routing desktop tasks through `MAP.md`, admin web tasks through `MAP.admin.md`, and backend tasks through `MAP.backend.md` before broad search.
- `.github/roles/map.role.md` - Documents how to create and update the split workspace maps for desktop, admin web, and backend work.
- `.github/roles/task.role.md` - Documents how to create and update `TASK.md` as the persistent task tracker.

## maps
- `MAP.md` - Maps the desktop app surface under `frontend/` plus shared workspace files used for desktop-first routing.
- `MAP.admin.md` - Maps the standalone admin web surface under `admin-frontend/`.
- `MAP.backend.md` - Maps the Flask backend surface under `server/` plus backend runtime files at the workspace root.
