# MAP.shared.workflow

## workspace root
- `.github/agents/coder.agent.md` - Defines the plan-first coding workflow and the map-reading order for this repository.
- `.github/roles/map.role.md` - Defines the index-plus-child-map structure and update rules for repository routing docs.
- `.github/roles/task.role.md` - Defines the persistent `TASK.md` structure, update rules, and validation tracking expectations.
- `TASK.md` - Tracks active work, backlog follow-ups, validation state, and completed changes for the repo.
- `MAP.md` - Acts as the top-level workspace map index that routes readers into the correct child map files.

## workflow references
